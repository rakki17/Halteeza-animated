# Halteeza Tech & Solutions — Premium Animated Website

A GitHub Pages-ready static website built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — complete website content
- `styles.css` — responsive visual system and animations
- `script.js` — scroll reveals, mobile navigation, tilt, magnetic buttons and progress bar
- `assets/founder-balaji.png` — founder image

## GitHub Pages
1. Upload all files/folders to the repository root.
2. Keep `index.html`, `styles.css`, `script.js` in the root.
3. Keep the `assets` folder and the founder image inside it.
4. GitHub → Settings → Pages → Source: **Deploy from a branch** → Branch: **main** → Folder: **/ (root)** → Save.
5. Wait for the Pages deployment to finish, then open the generated site URL.
